# Дневной сектор

Стартовый Vercel-проект для почасового запуска «Дневного сектора».

## Эндпоинты
- `/api/health` — проверка работы сервиса.
- `/api/run` — запуск генерации выпуска.

## Переменные окружения
- `OPENAI_API_KEY` — ключ OpenAI API.
- `OPENAI_MODEL` — необязательно; по умолчанию `gpt-5`.
- `CRON_SECRET` — секрет для защиты cron-запуска.

## Расписание
`vercel.json` настроен на запуск `/api/run` каждый час.

Важно: наличие почасового cron зависит от действующих ограничений выбранного тарифа Vercel.
