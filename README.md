# Первая версия НИД закрыта

20 октября 2026 года Иван подтвердил окончательное прекращение работы первой версии проекта «Необходимо и достаточно» и всех прежних «секторов».

Из действующей ветки удалены GitHub Actions workflow «Дневной сектор», почасовое расписание Vercel и серверные обработчики генерации. Зависимость OpenAI SDK также удалена. Этот репозиторий больше не содержит запускаемых заданий или кода обращений к API генерации.

Прежние инструкции по запуску, публикации и восстановлению «Дневного», «Утреннего», «Вечернего» и других «секторов» отменены. Для второго запуска НИД этот репозиторий не используется.

Изменения исходного кода не являются подтверждением удаления ранее развёрнутой копии в Vercel. Если такая копия существует, её расписания и функции необходимо отключить в самом Vercel. Действующий deployment через доступное подключение на момент закрытия проверить не удалось.

История Git сохранена только как архив; восстановление и запуск старой версии не предусмотрены.
